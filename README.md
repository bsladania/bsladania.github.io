# Bikramjeet Ladania — Portfolio

Static GitHub Pages portfolio. No build step is required.

## Publish
1. Copy all files in this folder into the root of the `bsladania.github.io` repository.
2. Commit and push to the default branch.
3. In GitHub → Settings → Pages, deploy from the branch root if Pages is not already enabled.

## Files
- `index.html` — page content
- `styles.css` — responsive design
- `script.js` — navigation/reveal interactions
- `assets/icons/` — locally bundled brand/product SVGs
- `Bikramjeet_Ladania_Resume.pdf` — résumé download

The site has no external runtime dependencies, so the icons and layout still work if a CDN is unavailable.
